# SVM Görüntü İşleme

## Amaç

Bu proje, görüntü işleme verileri üzerinde destek vektör makineleri yöntemiyle sınıflandırma yapılmasını amaçlamaktadır. Çalışma, görüntülerden elde edilen özelliklerin sınıflandırma sürecinde nasıl kullanılabileceğini göstermektedir.

## Çalışma Biçimi

Uygulama MATLAB ortamında çalıştırılmak üzere hazırlanmıştır. `SVM.m` dosyası çalıştırıldığında veri hazırlama, model eğitimi ve sınıflandırma adımları aynı akış içinde yürütülür.

## Kullanım

Proje MATLAB ile açılır ve `SVM.m` dosyası çalıştırılır. Kullanılan veri dosyalarının kodda belirtilen konumlarla uyumlu olması gerekir.
